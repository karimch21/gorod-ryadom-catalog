# Каталог «Город рядом»

[Каталог на GitHub Pages](https://karimch21.github.io/gorod-ryadom-catalog/) содержит 70 мест в Казани, Москве и Санкт-Петербурге. В карточках есть русские и английские описания, координаты и фотографии. Авторство и лицензии фотографий указаны в карточках и на странице каталога. Снимки уменьшены по сравнению с оригиналами.

- [manifest.json](https://karimch21.github.io/gorod-ryadom-catalog/manifest.json) задаёт список городов. Файл города из папки `cities/` содержит места и переводы. Фотографии лежат в `remote/`.
- Для проверки в Android 0.9.0 и iOS 0.10.0 используйте адрес `https://karimch21.github.io/gorod-ryadom-catalog/pilot/` в разделе «Тестовый каталог». Для теста доступны 50 мест Казани и по пять мест Москвы и Санкт-Петербурга. У тестовых городов отдельные идентификаторы.

Каталог публикуется из ветки `main`. При правках сохраняйте идентификаторы городов и мест. Для заменённых снимков задавайте новые пути, чтобы приложение загрузило их вместо ранее сохранённых копий.
